# זפזפן - Android TV

אפליקציה רזה ל-8 ערוצים (11, 12, 13, 14, 15, 16, 23, 99) עם **מסך קטן בתוך מסך גדול**: בזמן פרסומות עוברים לערוץ אחר, והערוץ המקורי ממשיך לרוץ בפינה (מושתק) עד שהפרסומות נגמרות.

## התקנה על ה-Mi Box
1. בטלוויזיה: להתקין מחנות Google Play את **Downloader** (של AFTVnews).
2. בהגדרות > אבטחה (או "אפליקציות") לאשר ל-Downloader **התקנה ממקורות לא ידועים**.
3. ב-Downloader להקליד:
   `https://github.com/evyatar-elad/zapper-tv/releases/latest/download/zapper-tv.apk`
4. התקנה. גרסה חדשה = אותו קישור, ומתקינים מעל (אותה חתימה).

## שלט
| כפתור | פעולה |
|---|---|
| **OK** | אין פינה: הערוץ הנוכחי עובר לפינה, והמסך הגדול עובר לערוץ הקודם. יש פינה: החלפה מיידית בין הגדול לקטן |
| **↑ / ↓** (או CH+/CH-) | ערוץ הבא / הקודם במסך הגדול |
| **← / →** | הזזת הפינה (4 פינות) |
| **ספרות** | מעבר ישיר (1 ואז 2 = ערוץ 12) |
| **חזור** | סגירת הפינה. בלי פינה: לחיצה כפולה ליציאה |
| **תפריט** | עזרה על המסך |

תרחיש: רואים 12, מתחילות פרסומות → **OK** (12 לפינה, 11 גדול עם קול) → נגמרו הפרסומות → **OK** (12 חוזר לגדול מיד, בלי טעינה).

## איך זה עובד
- רשימת הערוצים: `lineup/channels.json`. האפליקציה מורידה אותה מהריפו בכל הפעלה (אם הריפו ציבורי), ושומרת עותק. גיבוי: העותק שבתוך ה-APK.
- רוב הערוצים: כתובת HLS קבועה ופתוחה מאתר הערוץ (ל-13 עם `Referer`).
- קשת 12: כמו הנגן באתר mako, בקשה לכרטיס צפייה לשידור החי החינמי, וצירוף שלו לכתובת. אם mako דורשת התחברות, האפליקציה עוצרת ולא עוקפת.
- שני נגנים (Media3): הגדול באיכות מלאה, הקטן מושתק ומוגבל ל-480p / 1.2Mbps. בהחלפה רק מתחלפים המסכים.
- מקור שנכשל: עוברים לבא ברשימה; כולם נכשלו: הודעה וניסיון חוזר.
- פרסומות בתוך השידור החי לא מוסרות (הן חלק מהשידור). בשביל זה הפינה.

## סודות (פעם אחת)
ב-Settings > Secrets and variables > Actions: ‏`KEYSTORE_B64` ו-`KEYSTORE_PASS`. זה מפתח החתימה: אותו מפתח בכל בנייה, כדי שגרסה חדשה תותקן מעל הקודמת. לשמור עותק שלו גם אצלך.

## תחזוקה
- `build.yml`: כל דחיפה ל-main שמשנה קוד בונה APK ומפרסמת אותו.
- `upstream.yml`: פעם ביום משווה ל[רשימה של אפליקציית "מסך"](https://masach-lineup.yev-gavrikov.workers.dev/v1/lineup.json) (נבדקת אצלם אוטומטית). כתובת חדשה שם או כתובת שלנו שמסומנת שם כתקולה = Issue (מגיע במייל). עדכון: עריכת `lineup/channels.json`, בלי לבנות מחדש.
- בנייה מקומית: `./gradlew assembleRelease` (צריך Android SDK, ‏`local.properties` עם `sdk.dir`).
